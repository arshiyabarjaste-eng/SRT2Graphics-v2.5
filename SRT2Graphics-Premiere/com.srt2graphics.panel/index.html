قالب گرافیکی MOGRT ۱

استایل همه‌ی زیرنویس‌ها (فونت، رنگ، محل) از این قالب گرفته می‌شود. اگر قالب ندارید را ببینید — فقط یک بار، حدود ۱ دقیقه.

منبع زیرنویس ۲

هنوز فایلی خوانده نشده

استایل (اختیاری) ۳

اگر خالی بمانند، استایل از قالب استفاده می‌شود. تغییر فونت فقط وقتی اعمال می‌شود که کنترل فونت در قالب فعال شده باشد.

مقصد ۴

لایه‌ها روی اولین ترک ویدیوییِ خالیِ زیر کلیپ زیرنویس قرار می‌گیرند.

بعد از بارگذاری SRT محاسبه می‌شود
پریمیر را باز کنید، همین SRT و قالب را انتخاب کنید و در کادر روبه‌رو «آخرین لایه‌ی سالم + ۱» را بنویسید (لایه‌های ذخیره‌شده هر ۱۰ تاست — بهترین نقطه: مضرب ۱۰ + ۱). پنل هم شماره‌ی پیشنهادی را در گزارش نشان می‌دهد.

بدون پیغام حین تبدیل (همیشه فعال): بعد از قرارگیری هر لایه زیرنویس هیچ پیغامی به شما نشان داده نمی‌شود — فقط نوار پیشرفت به‌روز می‌شود؛ خطاها و گزارش پایانی همیشه نمایش داده می‌شوند.

موتور بیکری متن فارسی را مستقیم داخل فایل قالب کاشته می‌کند و پریمیر آن را مثل یک قالب عادی باز می‌کند — متن هیچ‌وقت از پل اسکریپت رد نمی‌شود، پس دیگه خراب نمی‌شود و محدودیت طول متن هم ندارد. حالت نوشتن فقط وقتی به کار می‌آید که موتور روی «نوشتن مستقیم» باشد.

نکته‌ی v2.4 — ریشه‌یابی کرش: پریمیر هنگام ایمپورت قالب دومِ بیکری به‌خاطر «هویت‌های تکراری اشیاء» داخل فایل‌های قالب کرش می‌کرد (مکث هم جلویش را نمی‌گرفت). حالا هر فایل بیکری هویت‌های یکتای خودش را دارد؛ جمع‌کردن حافظه بین لایه‌ها هم کاملاً حذف شد (خودش عامل ناپایداری بود) و اگر باز هم جایی کرش شد، با «ادامه از لایه» از همان‌جا ادامه می‌دهید — بدون ساختن مجدد لایه‌های قبلی.

نکته‌ی v2.3 — سبک‌سازی رم: متن‌های تکراری فقط یک‌بار ایمپورت می‌شوند و برای بقیه از همان قالب مشترک کپی می‌شود (در دیالوگ‌ها تا ۳۰٪ ایمپورت کمتر)، پروژه هر ۱۰ لایه یک‌بار به‌صورت امن ذخیره می‌شود (اگر کرش شد، کار ساخته‌شده از دست نمی‌رود). اگر پریمیر همچنان کرش کرد: Preferences → Memory را روی بهینه‌سازی برای Memory بگذارید و Media Cache را پاک کنید.

نکته‌ی v2.2 — ضدکرش کامل: ذخیره‌سازی خودکار پریمیر در طول تبدیل موقتاً خاموش می‌شود، پروژه قبل از شروع ذخیره می‌شود، مکث بین لایه‌ها هوشمند است (اگر لایه‌ای ناموفق شود خودکار بیشتر می‌شود) و در موتور نوشتن مستقیم، قالب فقط یک‌بار ایمپورت می‌شود. فایل‌های بیکری در Documents\SRT2Graphics\Baked ذخیره می‌شوند — تا وقتی پروژه باز است پاک‌شان نکنید.

۰٪

گزارش

آماده.

ساخت قالب گرافیکی در ۴ قدم (یک‌بار برای همیشه)

  1. در پریمیر، بالای فریم اول یک متن جدید بسازید (ابزار Type یا دکمه‌ی T) و برای متن نمونه، یک خط بلند (حدوداً ۲۵۵ کاراکتر) تایپ کنید — چندین بار کلمه‌ی «زیرنویس» را کپی کنید تا خط پر شود. مهم: پریمیر طول متن قالب را سقف ظرفیت همه‌ی زیرنویس‌های بعدی می‌گیرد؛ متن نمونه‌ی کوتاه = زیرنویس‌های بلندتر پاک می‌شوند.
  2. از پنل Essential Graphics فونت، اندازه، رنگ، سایه و محل متن را دقیقاً مثل یک زیرنویس واقعی تنظیم کنید. سطر متن را پایین و وسط کادر بگذارید.
  3. در همان پنل، منوی همبرگری ← Export Motion Graphics Template را بزنید؛ نام دلخواه بدهید و مسیر ذخیره را روی دیسک (مثلاً دسکتاپ) انتخاب کنید تا فایل .mogrt ساخته شود.
  4. در همین پنل دکمه‌ی «انتخاب فایل قالب» را بزنید و همان فایل را انتخاب کنید؛ سپس با دکمه‌ی «تست قالب» صحت آن را بررسی کنید. تمام!

نکته: قالب فقط باید یک لایه‌ی متن داشته باشد. اگر قالب را عوض کنید، همه‌ی تبدیل‌های بعدی با استایل جدید انجام می‌شود.

نکته‌ی v1.5: دکمه‌ی «تست قالب» حالا ۶ کلیپ آزمایشی می‌سازد — گزارش پارامترها + چهار کلیپ شوترا («۱ یونیکد + سند ASCII»، «۲ بایتی»، «۳ یونیکد + متن خام»، «۴ سند بدون پیشوند») + کلیپ ۶ «بیکری» که متنش از قبل داخل قالب کاشته شده. اگر فقط «بیکری» متن فارسی سالم نشان داد، همان موتور پیش‌فرض است و کارتان تمام است — حالت نوشتن لازم نیست.

نکته: اگر «تست قالب» خط‌های n=[hex] نشان داد، آن‌ها تصویر واقعی بایت‌های برگشتی از پریمیرند — اگر هیچ حالتی جواب نداد، همین خط‌ها را گزارش کنید.
